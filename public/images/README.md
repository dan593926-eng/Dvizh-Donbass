# Изображения

Все изображения, которые сейчас лежат здесь, — локальные атмосферные placeholder-artworks без внешних запросов.

Замени их своими лицензированными фото, сохранив имена, либо измени пути в `src/config/siteData.ts`.

Для production рекомендуется:
- WebP/AVIF для больших фото;
- отдельный мобильный вариант для hero, если он нужен;
- не использовать огромные исходники без ресайза.
