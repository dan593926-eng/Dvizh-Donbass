# ДВИЖ ДОНБАСС — сайт движения

Одностраничный сайт на React + TypeScript + Vite + Tailwind CSS + Framer Motion.
Весь контент (тексты, ссылки, фото, музыка, видео, история) меняется в файлах
`src/config/` и `src/data/` — трогать компоненты не нужно.

---

## 1. Размещение на GitHub Pages (пошагово)

Сайт публикуется автоматически: вы загружаете файлы в репозиторий, GitHub сам
собирает проект и выкладывает его. Файл автосборки уже лежит в проекте:
`.github/workflows/deploy.yml`.

### Шаг 1. Создайте репозиторий
1. Зайдите на github.com → кнопка **New** (новый репозиторий).
2. Название, например, `dvizh-donbass`. Тип — **Public**
   (на бесплатном тарифе GitHub Pages работает только с публичными репозиториями).
3. Не ставьте галочки «Add README» и т.п. — нажмите **Create repository**.

### Шаг 2. Загрузите файлы

**Вариант А — через командную строку (надёжнее всего).** В папке проекта:

```bash
git init
git add .
git commit -m "Первая версия сайта"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/dvizh-donbass.git
git push -u origin main
```

**Вариант Б — программа GitHub Desktop** (без командной строки):
File → Add local repository → выберите папку проекта → Publish repository.

> ⚠️ Не загружайте файлы перетаскиванием через сайт GitHub: при таком способе
> часто теряется скрытая папка `.github`, и автосборка не запустится.
> Если всё-таки грузите через браузер, проверьте, что в репозитории
> появилась папка `.github/workflows` с файлом `deploy.yml`.
> На macOS папки, начинающиеся с точки, скрыты — показать их: `Cmd + Shift + .`

Папку `node_modules` и `dist` загружать не нужно (они уже в `.gitignore`).

### Шаг 3. Включите GitHub Pages
1. В репозитории: **Settings → Pages**.
2. В блоке **Build and deployment → Source** выберите **GitHub Actions**.

### Шаг 4. Дождитесь публикации
Откройте вкладку **Actions** — там появится задача «Deploy to GitHub Pages».
Через 1–3 минуты она станет зелёной, и сайт откроется по адресу:

```
https://ВАШ_ЛОГИН.github.io/dvizh-donbass/
```

Если задача красная — нажмите на неё, откройте шаг с ошибкой и пришлите текст ошибки.

### Дальнейшие обновления
Любое изменение, отправленное в ветку `main` (`git add . && git commit -m "..." && git push`),
автоматически пересобирает и обновляет сайт.

### Особые случаи
- **Репозиторий `ВАШ_ЛОГИН.github.io`** — сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/`.
  Ничего менять не нужно, это определяется автоматически.
- **Свой домен** (например, `dvizh-donbass.ru`): Settings → Pages → Custom domain.
  Затем в `.github/workflows/deploy.yml` в шаге `Build` добавьте:
  ```yaml
        - name: Build
          run: npm run build
          env:
            BASE_PATH: /
  ```

## 2. Запуск на своём компьютере (необязательно)

Нужен Node.js 18 или новее (https://nodejs.org).

```bash
npm install       # установить зависимости (один раз)
npm run dev       # открыть сайт локально — адрес покажется в терминале
npm run build     # проверочная сборка, как на GitHub
npm run typecheck # проверка TypeScript
```

## 3. Как добавлять контент

| Что | Где редактировать | Куда класть файлы |
| --- | --- | --- |
| Тексты, меню, слоганы, соцсети | `src/config/siteData.ts` | — |
| Фотогалерея | `src/data/gallery.ts` | `public/images/gallery/` |
| Карточки «Культура движа» | `src/config/siteData.ts` → `cultureItems` | `public/images/culture/` |
| Фон секции «Где ты — там и движ» | — | `public/images/movement/crowd.jpg` |
| Фон первого экрана (фото/видео) | `src/config/siteData.ts` → `hero` | `public/images/hero/`, `public/videos/` |
| Музыка | `src/data/tracks.ts` | `public/audio/` |
| Видео | `src/data/videos.ts` | `public/videos/` |
| История (таймлайн) | `src/data/timeline.ts` | — |
| Логотип | — | `public/images/brand/` |

**Пути к файлам всегда пишите от папки `public`, начиная со слеша:**
`/images/gallery/01.jpg`, `/audio/trek.mp3`. Сайт сам поправит их под адрес GitHub Pages.

Пока файла нет, на его месте показывается аккуратная тёмная заглушка —
сайт не ломается, но выглядит пустовато. Добавьте свои фото, и он оживёт.

### Фото в галерею
1. Положите файл в `public/images/gallery/`, например `11.jpg`.
2. Добавьте строку в `src/data/gallery.ts`:
   ```ts
   { id: "g11", src: "/images/gallery/11.jpg", alt: "Что на фото", span: "tall" },
   ```
   `span` — размер плитки: `"tall"` (высокая), `"wide"` (широкая), `"big"` (большая)
   или не указывать (обычная). `id` должен быть уникальным.
3. Удалить фото — удалить строку. Порядок строк = порядок в галерее.

### Карточки «Культура движа»
Имена файлов должны совпадать с `id` карточек:
`music.jpg`, `concerts.jpg`, `terikony.jpg`, `friends.jpg`, `street.jpg`,
`road.jpg`, `memory.jpg` — в папке `public/images/culture/`.
Лучше вертикальные фото (пропорция 3:4).

### Ускорение загрузки фото (рекомендуется)
Фото с телефона весят 3–8 МБ — это главная причина «лагов» сайта.

```bash
npm install -D sharp   # один раз
npm run images
```

Скрипт создаст рядом с каждым фото лёгкие версии `-800.webp` и `-1600.webp`
и напечатает готовую строку. Вставьте её в поле `srcSet` нужного фото:

```ts
{
  id: "g1",
  src: "/images/gallery/01.jpg",
  srcSet: "/images/gallery/01-800.webp 800w, /images/gallery/01-1600.webp 1600w",
  alt: "Толпа на концерте",
  span: "big",
},
```

Телефон загрузит версию на 800 px, большой монитор — на 1600 px.
Даже без скрипта сожмите фото хотя бы до ~2000 px по длинной стороне.

### Фон первого экрана
В `src/config/siteData.ts`, объект `hero`:
```ts
backgroundImage: "/images/hero/crowd.jpg",
backgroundVideo: "/videos/hero.mp4",   // необязательно
```
Видео: mp4 без звука, 10–20 секунд, до ~5 МБ. Можно указать только картинку.
Если оставить пустые строки — будет фирменный фон с терриконами и светом прожекторов.

### Музыка
> Добавляйте только свои треки или те, на публикацию которых у вас есть разрешение.
> Размещение чужой музыки без прав может привести к блокировке репозитория.

1. Файл — в `public/audio/`, например `01.mp3`.
2. В `src/data/tracks.ts` раскомментируйте пример и заполните:
   ```ts
   { id: "t1", title: "Название", artist: "Исполнитель", src: "/audio/01.mp3", cover: "/images/gallery/01.jpg" },
   ```
Пока треков нет, в секции показывается подсказка вместо пустого плеера.
У GitHub ограничение 100 МБ на файл и ~1 ГБ на сайт — для музыки этого хватит на десятки треков.

### Видео
Аналогично музыке: файл в `public/videos/`, запись в `src/data/videos.ts`
(`title`, `src`, `poster` — картинка-превью). Для длинных роликов лучше
загружать их на YouTube и давать ссылку в соцсетях — GitHub не предназначен для тяжёлого видео.

### Соцсети
`src/config/siteData.ts` → `socialLinks`. Замените `https://t.me/your_channel`
и остальные ссылки на настоящие. Иконки для `telegram`, `instagram`, `vk`, `youtube`
подставятся сами.

### История
`src/data/timeline.ts` — **даты и события сейчас примерные, замените их на
реальную историю вашего движения.**

### Интро и бегущие строки
- `intro.enabled: false` в `siteData.ts` — выключить заставку при входе.
- `tickers` — фразы в бегущих строках между секциями.

### Логотип
Файлы в `public/images/brand/`:

| Файл | Где |
| --- | --- |
| `logo.png`, `logo.webp` | первый экран |
| `logo-sm.png`, `logo-sm.webp` | шапка и подвал (≈360 px шириной) |
| `logo-mark-512.png` | превью ссылки в мессенджерах |
| `favicon-32.png`, `apple-touch-icon.png` (в `public/`) | иконка вкладки / ярлык на телефоне |

Новый логотип должен быть **PNG с прозрачным фоном** — иначе на тёмном сайте
будет белый прямоугольник. Замените файлы с теми же именами.

## 4. Что есть на сайте

- Интро-заставка ~2 с (чёрный экран → шум плёнки → «ДВИЖ» → «ДОНБАСС»),
  один раз за визит, пропуск кликом или клавишей.
- Первый экран: логотип, параллакс терриконов, засветы плёнки, «пыль» в свете прожекторов, сканлайны.
- Бегущие строки между секциями — жёлтая лента-росчерк из логотипа.
- Секции: О движении, Культура (горизонтальная лента), Музыка (плеер с визуализацией звука),
  История, Фото (мозаика + полноэкранный просмотр: стрелки, клавиатура, свайп),
  Видео, «Где ты — там и движ», Контакты.
- Кастомный курсор и «магнитные» кнопки — только на компьютере.
- Мобильное полноэкранное меню.

## 5. Производительность и доступность

- Код разбит на части, библиотеки кешируются отдельно.
- Фото грузятся лениво, поддерживается `srcset` (см. «Ускорение загрузки фото»).
- Музыка и видео не скачиваются, пока их не включили.
- Частицы останавливаются, когда первый экран не виден или вкладка свёрнута;
  на телефонах их вдвое меньше, размытие засветов слабее, параллакс мягче.
- Никаких тяжёлых размытий (`filter: blur`) и режимов наложения во время прокрутки:
  засветы сделаны градиентами, зерно плёнки статичное. Замер при прокрутке: 60 кадров/с
  (до оптимизации было 11–12).
- На слабых устройствах (≤ 4 ядер, ≤ 4 ГБ памяти или экономия трафика) автоматически
  включается облегчённый режим: без частиц, без анимации засветов и бегущих строк.
- При системной настройке «Уменьшить движение» (`prefers-reduced-motion`)
  заставка, частицы, курсор и бегущие строки отключаются.
- Видимая рамка фокуса для управления с клавиатуры, подписи для скринридеров.

## 6. Что проверено и что нет — честно

Проверено автоматически в браузере Chromium (с упрощёнными заменами анимационной
библиотеки): страница загружается без ошибок JavaScript; все пункты меню ведут на
существующие секции; пути к файлам правильно работают по адресу вида
`/имя-репозитория/`; интро появляется, исчезает и не повторяется в той же сессии;
лайтбокс открывается, листается стрелками и закрывается Escape; мобильное меню
открывается и закрывается на ширине 375 px; при `prefers-reduced-motion`
интро и частицы отключены. Скрипт оптимизации фото проверен на тестовом изображении.
Типы TypeScript проверены.

**Не проверено визуально:** в среде разработки не было доступа к интернету для установки
Tailwind и Framer Motion, поэтому внешний вид на ширинах 320–1920 px я не видел
своими глазами. Первая полноценная сборка произойдёт на GitHub Actions.
После публикации откройте сайт на телефоне и компьютере; если что-то выглядит
не так или сборка упала — пришлите скриншот или текст ошибки.

```

scripts/optimize-images.mjs    сжатие фото (npm run images)
public/

├── images/gallery/   фотогалерея
├── images/culture/   карточки «Культура движа»
├── images/movement/  фон секции «Движ»
├── images/hero/      фон первого экрана (по желанию)
├── audio/            музыка
└── videos/           видео
src/
├── config/siteData.ts  ← ВСЕ тексты и ссылки
├── data/               ← фото, треки, видео, история
├── sections/           секции страницы
├── components/         элементы интерфейса
├── animations/         анимации
├── hooks/              служебные хуки
├── lib/asset.ts        пути к файлам под GitHub Pages
└── styles/globals.css  глобальные стили и эффекты
```
